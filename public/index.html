O que é o Null.chat?

O Null.chat é um fórum anônimo de imagens. Sem cadastro, sem senhas, sem coleta de dados. Você não precisa de uma conta para postar, e nós não salvamos o seu IP. O anonimato aqui é levado a sério.

Sinta-se livre para navegar pelos boards, postar imagens, criar threads e responder. Para responder a alguém, use o botão [Responder] ou digite >>ID no texto para citar um post. Lembre-se de ler as regras antes de postar: não é permitido conteúdo ilegal, spam ou ataques pessoais.

Se curtir o projeto, compartilhe o link com os amigos. O Null.chat é feito por anônimos, para anônimos.
