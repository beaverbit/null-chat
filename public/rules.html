Regras do Null.chat

O Null.chat é um espaço para discussões anônimas. Para manter o ambiente minimamente utilizável e evitar problemas legais, temos algumas regras básicas. O descumprimento pode resultar na remoção do post ou banimento do IP.

1. Conteúdo Proibido (Banimento Imediato)

  • Conteúdo ilegal: Nada de pornografia infantil, zoofilia, apologia a crimes ou instruções para fabricação de armas/explosivos.
  • Doxxing (OSINT): É estritamente proibido postar informações pessoais de outros usuários (nomes reais, endereços, telefones, redes sociais). O anonimato de todos deve ser respeitado.
  • Spam e Phishing: Links maliciosos, golpes financeiros, pirâmides ou divulgação excessiva de outros sites.

2. Comportamento no Board

  • Flood: Evite criar várias threads seguidas com o mesmo assunto. Se quiser complementar algo, use o botão [Responder].
  • Spam de imagens: Não poste a mesma imagem repetidamente. Imagens inúteis ou fora de contexto podem ser removidas.
  • Ataques pessoais: Discussões acaloradas são normais em fóruns anônimos, mas perseguição direcionada a um usuário específico (stalking) não será tolerada.

3. Como usar o site

  • Citações: Use >>ID (ex: >>123) para responder a alguém. O post citado ficará com um link verde.
  • Sage: Se quiser responder a uma thread sem fazê-la subir para o topo da página inicial, marque a caixa "Sage (não bumpar)".
  • Apagar posts: O seu navegador guarda um token secreto para que você possa apagar o próprio post clicando em [Apagar]. Se você limpar o cache do navegador, perde esse direito.
  • Denúncias: Se vir algo que viole as regras, clique em [Reportar]. O administrador irá analisar.

4. Privacidade

Nós não salvamos IPs, não usamos cookies de rastreamento e não exigimos e-mail. A única forma de identificação é o seu token de exclusão (que fica no seu navegador). Mantenha o anonimato e não compartilhe informações reais.
